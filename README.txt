JOY RIDE KITA CALCULATOR

App title and in-app title: JoyRide Kita Calculator

FEATURES
- MC Taxi fare estimate using the supplied sample distance/fare points
- Editable platform commission
- Editable gas price (PHP per liter)
- Editable fuel efficiency (km per liter)
- Automatic fuel liters and gas expense calculation
- Actual profit after platform commission and estimated gas expense
- Earnings and gas history saved on this browser/device
- CSV export
- Offline support after first visit on an HTTPS-hosted website

IMPORTANT
This is an estimate, not an official JoyRide fare table. The fare calculation uses straight-line interpolation between the supplied sample points and extends the nearest segment outside the sample range. Actual fares may differ. Fuel expense is estimated from the gas price and km/L values you enter.

HOW TO USE
1. Upload the contents of this folder to a static web host that serves HTTPS.
2. Open the published website in Chrome on Android.
3. In Chrome, tap the three-dot menu, then choose "Add to Home screen" or "Install app" if shown.
4. Open it once while online. After that, the cached app can be opened offline.
